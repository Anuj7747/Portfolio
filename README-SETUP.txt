PORTFOLIO REVIEWED UPDATES — SETUP

FILES INCLUDED
- index.html
- style.css
- script.js
- updates.json

INSTALL IN VS CODE
1. Download and extract portfolio-review-updates.zip.
2. Open your existing portfolio project folder in VS Code.
3. Make a backup of the existing index.html, style.css, and script.js.
4. Copy the four extracted files into the portfolio project folder and replace matching files when prompted.
5. Save all files (Ctrl+S).
6. Run the site with your existing Live Server workflow. For updates.json fetching to work, open it through a local server (e.g. Live Server), not by double-clicking index.html.
7. Open the Activity section. Fill the form and click Save as draft.
8. Under Items awaiting review, click Approve for each item you want to publish. Remove anything you do not want.
9. Click Export approved updates.json. The browser downloads a file named updates.json.
10. Replace the project's updates.json with the downloaded file.
11. Test the Activity section again. Approved exported items should now appear in the public updates list.
12. When satisfied, commit and push the four project files to GitHub and deploy as you normally do.

IMPORTANT
- Drafts are stored in localStorage in this browser only. They are not automatically synced between devices or browsers.
- Only items marked Approved and exported into updates.json are prepared for public display.
- To remove a published item, edit/review the draft list, export a new updates.json containing only approved items you want public, replace the project file, then redeploy.
- ChatGPT conversations are not automatically accessible to this website. Add only the questions/solutions you choose to share.
- LeetCode and CodeChef progress is manually entered in this version. Automatic account syncing requires a separate reliable API/integration.
- Never add passwords, private tokens, personal information, or confidential content to public updates.
